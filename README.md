# 🎨 Portfolio Website

A modern, responsive personal portfolio website showcasing professional work, skills, and capabilities. This project serves as both a portfolio piece and a platform to demonstrate proficiency in web development technologies.

## 📋 Overview

This is a professional portfolio website built with vanilla HTML, CSS, and JavaScript. The site features a clean, modern design with smooth navigation and interactive elements. It's designed to present a cohesive personal brand while highlighting key projects and technical skills.

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shade5772/Portfolio-Website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Portfolio-Website
   ```

3. Open `index.html` in your browser or serve using a local web server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js (with http-server)
   npx http-server
   ```

4. Visit `http://localhost:8000` (or your configured port) in your browser

## 💡 Usage

The portfolio is a static website with simple navigation:
- Use the header navigation to jump to different sections
- Click on projects to view detailed project pages
- Access social media and contact links from the about section
- Download resume from the skills section

## 🔧 Customization

To customize this portfolio for your own use:

1. **Update Personal Information:**
   - Modify hero text and descriptions in `index.html`
   - Update social media links with your profiles

2. **Update Profile Image:**
   - Replace `images/Profile_10.png` with your profile picture
   - Update image alt text for accessibility

3. **Add/Remove Projects:**
   - Modify the projects section in `index.html`
   - Add project images to the `images/` folder
   - Create corresponding project pages in `projects/` folder

4. **Customize Styling:**
   - Edit CSS variables in `style.css` to change colors
   - Modify fonts and typography in CSS imports
   - Adjust responsive breakpoints as needed
